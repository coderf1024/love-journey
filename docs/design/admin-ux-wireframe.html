D3 · 怎么做到「14px 视觉 + 不放大」需要真机确认

① 视觉 14px，计算字号仍 16px推荐

iOS 判断是否放大只看输入框的计算 font-size。输入框保持 font-size: 16px（不触发放大），再用 transform: scale(0.875) + width: 114.29% 把视觉缩到 14px。布局不跳、字号不放大、也不会有“关键盘回不去”。

② viewport 关缩放只对部分浏览器有效

maximum-scale=1, user-scalable=no 在 iOS 10+ Safari 会被忽略（它只管输入聚焦放大之外的手势），但在微信内嵌 WebView / 部分安卓上有效。可以加，但不能只靠它。

③ 禁双击 / 捏合兜底

touch-action: manipulation 去掉双击放大；gesturestart 阻止捏合。只禁页面缩放，输入框内的选词、光标拖动不受影响。

④ 回退方案

若 ① 在某个 iOS 版本上出现文字发虚或光标错位，回退成「聚焦瞬间 16px、失焦回 14px」；页面只在聚焦时轻微位移，不会持续放大。

验收方式（真机）：聚焦任意输入框 → 页面不放大、键盘收起后布局不变；双指捏合 → 不缩放；输入框内长按选词、光标拖动正常；文字不模糊、光标位置与实际文字对齐。
