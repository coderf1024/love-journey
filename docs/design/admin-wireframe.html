评审时想确认的几点

  1. 出餐时按菜逐道拍，一单有 2 道菜就要求 2 张成品图；每道菜未拍完不能出餐。确认这个强约束？
  2. 出餐弹窗里除了「拍照」直接调系统相机，是否保留「从相册选」作为备用入口？线框里先保留了。
  3. 图片集按顺序保存，第一张即主图：设为主图等于移到第一张，拖动排序可改变顺序，拖到第一位自动成为主图；删除主图时下一张自动补位。这样处理？
  4. 出餐成品图只出现在菜品详情页的图片集，还是也要在订单详情/历史里展示？线框里只放在菜品详情。
  5. 图片数量不限；单张仍走现有压缩（最大 1600px、JPEG）。这样是否可以？
