六一的动态

把六一做成类似朋友圈的个人主页：顶部背景图，头像压在左下角，下面是按时间降序的动态流，每条是文字 + 多张图片。用户端可以直接发动态（右下角悬浮按钮），管理端也能发，并只管名字、头像、背景图、一句话这些基本信息。本页是线框，不访问 OSS、不发 Bark。

发动态：右下角悬浮按钮 头像：压背景图左下 发帖权限：用户 + 管理端都能发 底栏仍是 我们 / 小灶 / 恋爱卡 / 空间

这一版的关键变化

  • 原来的「重要事件」变成动态：文字 + 多图，按发布时间倒序。
  • 用户端可以直接发，右下角悬浮 ＋；管理端也能发。
  • 管理端只管名字 / 头像 / 背景图 / 一句话 / 到家日。
  • 顶部从「一张大形象图」改成朋友圈式背景图 + 压边头像。

已修复的 bug

你反馈管理端保存不上：原因是 admin.html 里的处理函数同名调用了自己（savePetProfile 无限递归），所以点多少次都没写入。已改名为 handleSavePetProfile，现在保存能落库。

待你确认

1动态能不能只有图没有文字？（现在设计成「文字和图片至少有一个」）

2点赞和评论要不要做？现在只画了「♥ 2 / 评论」占位，二期再做也行。

3动态要不要标签（日常 / 第一次 / 吃饭 / 睡觉）？还是像朋友圈一样只有文字和图片？

4动态能不能删除 / 编辑？管理端能删；用户端自己发的能不能删？

5背景图默认用什么？纯渐变、趴姿图，还是等一张新素材？

数据与实现（供参考）

  • content/pet.json 增加 cover（背景图）和 avatar；events[] 改为 moments[]（text / images[] / tag / author / createdAt）。
  • 用户端发动态要写 OSS，需要 warmOssSdk()；图片走 uploadPetImage()（保留 alpha）。
  • 不做分页，先取最近 50 条；超过再说。
