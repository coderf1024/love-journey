# LJ-20261025-004-admin-confirm-layer · 测试确认框被模板弹窗遮挡

- 状态：in-review
- 提出人：人
- 日期：2026-10-25
- 分支：`fix/LJ-20261025-004-admin-confirm-layer`

## 背景与目标

管理端通知模板弹窗里点「发送测试」，弹出的确认框（测试预览 · 出餐）被模板弹窗挡住，无法点击。

根因：`.admin-dialog`（通用确认框）`z-index: 100`，低于 `.admin-modal`（模板/出餐/菜品弹窗）`z-index: 110`。另外 Escape 处理顺序先判断底层弹窗，确认框打开时按 Escape 会关掉模板弹窗而不是确认框。

## 范围

- 要做：
  - 把 `.admin-dialog` 提到所有弹窗之上（`z-index: 140`）。
  - Escape 优先关闭确认框。
- 不做（非目标）：
  - 不改用户端 dialog/sheet 的层级。
  - 不改弹窗的打开/关闭动画和业务逻辑。

## 验收标准

1. 模板弹窗内点「发送测试」，确认框显示在最上层，可点击「确认发送 / 先不发」。
2. 确认框打开时按 Escape 只关闭确认框，底层模板弹窗保持。
3. 其他使用 `adminConfirm` 的场景（取消订单、删除卡片等）不受影响。

## 涉及面

- 页面：`admin.html` 的通用确认框和 Bark 模板弹窗。
- 数据/通知：无。
- 兼容/迁移：无。
