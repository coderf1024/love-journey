# LJ-20261026-005-filter-ui · 订单筛选吸顶与「全部」前置

- 状态：in-review
- 提出人：人
- 日期：2026-10-26
- 分支：`fix/LJ-20261026-005-filter-ui`

## 背景与目标

1. 用户端「我的订单」向下滚动时，`me-filters` 跟着列表一起滚走，希望像「恋爱流水」一样固定住筛选栏。
2. 管理端订单默认是「全部」，但「全部」仍排在筛选最后，应该放到第一个。

## 范围

- 要做：
  - 用户端订单和恋爱卡流水的筛选栏加吸顶容器，停在子页面标题下方。
  - 管理端 `ORDER_FILTERS` 把「全部」调整到第一项。
- 不做：
  - 不改筛选统计和排序逻辑。
  - 不改其他页面的 sticky 行为。

## 验收标准

1. 「我的订单」滚动时筛选栏停在子页面标题下方，列表从其下方滚过。
2. 恋爱卡流水的筛选栏同样吸顶。
3. 管理端订单筛选第一个是「全部」，默认选中它。
4. 筛选切换和订单数据正常。
