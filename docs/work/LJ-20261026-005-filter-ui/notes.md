# LJ-20261026-005-filter-ui · 笔记

## 决策

- 2026-10-26：用 sticky 容器而不是让列表内部滚动，避免嵌套滚动；容器加不透明背景遮住列表。
- 2026-10-26：子页面标题高度抽成 `--me-sub-head-h`，吸顶筛选栏按它偏移。

## 发现

- 筛选栏在 `me-sub-body` 内，直接 sticky 会在标题和筛选之间留出透出列表的缝隙，所以包一层带背景的容器。

## 后续调整

- 2026-10-26：订单页改为 `100dvh + flex` 固定视口、列表内部滚动（`LJ-20261026-006-orders-scroll`）；恋爱卡流水的吸顶已撤回，恢复原样。
