## 背景与目标

订单页已经改成“固定视口 + 列表内部滚动”，高度自适应。恋爱卡流水和恋爱币流水还是固定 `max-height: 420px`，希望统一成同一套布局。

## 范围

- 要做：
  - 把订单页的 `me-orders-page` 泛化为 `me-fixed-view`，覆盖订单、恋爱卡流水、恋爱币流水。
  - `.me-coupons` 和 `.wallet-entries.me-ledger` 改为 `flex: 1; min-height: 0; overflow-y: auto`。
  - 移除 `.me-coupons` / `.me-ledger` 的 `max-height: 420px`。
  - 各视图的标题、统计、筛选、钱包余额和区块标题固定。
- 不做：
  - 不改列表内容和筛选逻辑。
  - 不改订单详情、钱包 sheet 和页面其他部分。

## 验收标准

1. 恋爱卡流水列表在固定区域内滚动，统计和筛选不动。
2. 恋爱币流水列表在固定区域内滚动，余额卡片和“最近流水”标题不动。
3. 页面本身不滚动，列表不与子标题重合。
4. 320 / 390 / 1280 和横竖屏下列表高度自适应。
5. 订单页行为与上一版一致。
