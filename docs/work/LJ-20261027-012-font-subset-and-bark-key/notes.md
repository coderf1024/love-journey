# LJ-20261027-012 · 笔记

## 决策

- 2026-10-27：字体子集是静态文件，而菜品名由管理端动态新增，两者天然对不上。分两层修：构建脚本读线上 OSS 文档（保证当前内容全覆盖）+ `font-extra-chars.txt` 常用字/餐饮词（降低以后新增菜品缺字的概率）。
- 2026-10-27：常用字只并入 Noto Serif SC。Ma Shan Zheng 并入 2500 常用字后约 1.1MB，而它缺字会沿 `--font-cute` 回退到 Noto，视觉可接受，不值得为装饰字体付这个体积。
- 2026-10-27：管理端用户密钥、管理员密钥都改成明文 `text`（人决定：核对密钥时来回切换太麻烦，管理端本身有口令门禁）。

## 发现

- 线上菜单由管理端新增，缺字覆盖 虾 柿 炸 酱 米粉 咖 喱 椒 根 饼 擀 酥 等。频率表 3500 字仍缺 喱 / 擀 / 柿，说明纯频率表不够，必须并入线上文档 + 餐饮词表。
- `--font-cute` 的回退链是 `Ma Shan Zheng → Noto Serif SC → Songti SC`，所以 Ma Shan Zheng 的缺字最终仍由 Noto 兜住。

## 遗留风险 / 后续任务

- 字体子集仍需人工重建：管理端新增菜品用到的字若不在常用字/餐饮词内，会出现单字回退。可在管理端保存菜品时提示“请重新执行 build-fonts.sh”，或后续考虑字体按需加载。
- Noto 子集体积 568KB；如果以后觉得首屏慢，可删掉 `font-extra-chars.txt` 的常用字段落（保留餐饮词）再重建。
