# LJ-20261027-014 · 笔记

## 决策

- 2026-10-27：ECharts / qrcodejs 改为站内自托管。原因：`cdn.jsdelivr.net` 在微信 X5 和国内移动网络经常不可达，且新版改为滚动时动态注入，无法复用旧版静态 script 的微信缓存。

## 发现

- 阻断 jsdelivr 时，新版地图卡片显示「地图暂时打不开」，与用户描述一致。
- 旧版（a8189d0）用静态 `<script src="https://cdn.jsdelivr.net/...">`，失败时只是地图空白，不会提示。

## 遗留风险 / 后续任务
