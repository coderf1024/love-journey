- 2026-10-28：过渡态一直显示到管理端数据加载完成（`openAdmin` 里 `await loadAdmin()` 之后）才收起，避免先露出一个空面板。三条退出路径（登录成功、退出登录、恢复失败）都会清理 `admin-session-boot` 和 `#admin-boot`。

## 发现

- 原实现里「恢复登录失败会 `clearAdminSession()`」实际很难触发：`loadAdmin()` 自己 catch 了加载错误，所以网络失败时通常是面板空白 + toast，而不是清掉登录态。本次仍把 `clearAdminSession()` 移出该分支，避免以后改动让它变成真的清登录。
- `readAdminSession()` 只在页面加载时执行一次；标签页长期不关不会中途过期。
- 旧的 `sessionStorage` 记录无需迁移，关窗口自然消失。

## 遗留风险 / 后续任务

- iOS Safari / 微信内置浏览器的存储清理（约 7 天无交互）不可控，属于浏览器行为。
- 过渡态没有超时兜底：如果 OSS 数据请求长时间不返回，会一直停在「正在打开管理端…」。当前 OSS SDK 没有配置超时，网络失败时通常会较快报错并回落到登录页，暂不额外加计时器。
- 过渡态用的是固定的 `assets/media/space-avatar.svg` 头像，因为真实空间头像存在 OSS 里，首屏还读不到。
- 若以后想要「换口令即让所有设备失效」，可以在 token 里附口令摘要；当前未做。
