## 背景与目标

首页「山河共赏」地图的改造方向已在 `docs/design/home-map-wireframe.html` 中确认：

- 数据到城市，点亮到省份：一个省里只要有一个城市去过，整个省亮；
- 不再铺未去过的灰点；
- 境外城市不再挤进中国底图，用地图角落的印章表达；
- 底部城市列表改为三列平铺，一屏看全，不横向滑动。

同时，目前本地测试和线上共用 `love-journey/db`，本地任何下单/发卡/改状态都会直接写线上。需要一套隔离的测试库，避免开发验收污染线上数据。

线上当前 `cities.json` 共 18 条：17 个国内城市 + 济州岛；国内城市落在 15 个省级区域，其中北京（含古北水镇）和四川（含都江堰）各有两个城市，正好验证“同省多城只亮一次”。

## 范围

### 测试库

- 同一 bucket 下新增测试前缀 `love-journey/db-test`，不另建 bucket；
- `localhost` / 私有 IP 默认使用测试库；线上域名始终使用生产库；本地可用 `?env=prod` 显式查看生产库；
- 测试环境图片上传走 `love-journey/uploads-test/`；
- 测试环境默认跳过 Bark 推送（可用 `?bark=on` 临时打开）；
- 提供只读源库 → 写测试库的克隆脚本，支持 `--dry-run` / `--force`；
- 页面在测试库下显示一个不打扰的「测试库」角标。

### 地图

- 省级填色由城市记录归并：同省多城只亮一次，颜色取最早访问的城市；
- 7 个大区配色：华北 / 东北 / 华东 / 华南 / 华中 / 西南 / 西北，同区省份按访问时间由浅到深；低饱和，不为每座城市造新色；
- 保留城市级粉点和城市名；移除未访问 `scatter` 系列和「还没去」图例；
- 济州岛使用地图右下角的境外印章，显示最近一次境外城市和年月；
- 底部城市列表改为三列网格，18 条全部展示，无横向滚动；境外城市用 ✈ 标记；
- 顶部 badge 显示总城市数和境外数量，图例显示国内城市数。

### 非目标

- 城市详情卡 / 城市照片：现有 `cities.json` 只有名称和日期，没有可展示的描述/照片；留到后续任务；
- 世界地图 / 世界视图：境外城市到 8 个以上再评估；
- 足迹连线：已从设计中移除；
- 自动缩放视野、刷新保持视角：原型里有，本次先记录为后续优化（除非实现成本很低）。

## 验收标准

1. 本地 `localhost:8888` 打开时使用 `db-test`，页面有「测试库」角标；线上域名始终使用生产库；本地 `?env=prod` 可以查看生产库。
2. 克隆脚本 dry-run 只输出计划，不写任何数据；正式执行只写 `db-test`，不修改源库；测试库 `space.settings.bark.enabled=false`。
3. 地图点亮 15 个省级区域：北京（北京 + 古北水镇）和四川（成都 + 都江堰）各只亮一次；17 个国内城市点全部显示；没有灰点。
4. 济州岛不进入中国底图，右下角印章显示「济州岛 · 2025.05」；底部 18 个城市格全部可见，无横向滚动。
5. 320/390/1280 无横向溢出，console 无报错；缓存版本已 bump；字体如新增文案包含缺字已重建。
6. `docs/work/LJ-20261028-016-map-province-lighting/QA.md` 记录实际检查结果。

## 风险与开放问题

- [ ] 克隆测试库需要 OSS 凭据与人工执行；先 dry-run，再正式执行。
- [ ] 生产库中 `济州岛` 没有 `overseas/country` 字段；本次代码用内置境外名单兜底，后续可加字段迁移。
- [ ] 7 个大区色相需要人工确认视觉效果；已有原型可对照。
