## 背景与目标

「岁月留痕」的回忆目前只存在 OSS 的 `content/milestones.json`，管理端没有维护入口；011 又因为「没有图片来源」把用户端回忆封面统一改成了纯色渐变。

本需求分两步完成：

1. 管理端补上里程碑配置：新增、编辑、删除回忆，维护日期、标题、描述和 4:3 封面图。
2. 用户端回忆卡片和详情改为从 `content/milestones.json` 读取 `image`；管理端没配图片、或图片加载失败时，继续使用现有的纯色渐变背景。

## 范围

- 要做：
  - 管理端「系统 → 数据」和桌面侧栏新增「岁月留痕」入口。
  - 管理端列表按年份分组、日期倒序；搜索标题/描述；「全部 / 有封面 / 无封面」筛选。
  - 管理端新增/编辑弹窗：日期、标题、描述、封面图（上传或粘贴 URL）；封面按 4:3 预览。
  - 管理端删除回忆，使用现有自定义确认框。
  - 封面图上传到 OSS `uploads/milestones/`，客户端压缩（与菜品图一致）。
  - 用户端首页「岁月留痕」卡片和回忆详情读取 `image`，照片铺满 4:3 封面。
  - 用户端没有 `image` 或图片加载失败时，回退到现有 v0–v3 纯色渐变和 motif，不出现破图。
- 不做（非目标）：
  - 不做多图相册；一条回忆只有一张封面图。
  - 不做手动拖拽排序；展示顺序仍由日期决定（011 的规则不变）。
  - 不做用户端提交/编辑回忆。
  - 不做回收站、草稿、定时发布。
  - 不改 Bark、订单、钱包、恋爱卡。
  - 不改「全部回忆」时间线的文字列表；本次只给卡片和详情封面加图。

## 验收标准

1. 管理端「系统」页出现「岁月留痕」入口，显示总条数和有封面条数。
2. 管理端列表按日期倒序、年份分组，无日期条目归入「旧时光」并排最后。
3. 管理端支持搜索，以及「全部 / 有封面 / 无封面」筛选。
4. 管理端新增/编辑/删除回忆正常；保存写入 `content/milestones.json`。
5. 管理端上传封面后，列表缩略图和编辑预览显示新图。
6. 用户端首页回忆卡片：有 `image` 的显示照片，年份为白色叠层，日期胶囊保留。
7. 用户端回忆详情：封面显示同一张大图。
8. 管理端未配置图片的回忆，用户端仍显示原来的纯色渐变 + motif。
9. 图片 URL 失效时，用户端隐藏图片并回退纯色渐变，不出现破图图标。
10. 320 / 390 / 1280 下管理端列表/弹窗、用户端卡片/详情正常，console 无报错。
11. 缓存 token 已 bump；日期解析、字体和现有交互不受影响。
