## 缓存边界（说明）

- 缓存只是首屏快照，不是 TTL；每次**完整**读取都会覆盖它，展示窗口只有一次网络往返。
- 写操作（下单、取消、核销、发币、改状态）都会重新读取对应文档再校验，不依赖 `state` 里的缓存值。
- 懒加载地图只影响 ECharts/GeoJSON 的下载时机；OSS SDK 在首页不加载，在小灶 / 管理端 / 核销页空闲预热，只有“打开小灶后立刻点确认”的极端情况才可能等剩余加载，按钮会显示「下单中…」。
- 唯一的小窗口：菜单价格在缓存渲染到后台刷新之间（约 1 秒）可能显示旧值；下单以重新读取的菜单为准。菜单由大厨手动维护，变化很少。
