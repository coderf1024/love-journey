## 背景与目标

上线后发现：回忆详情的封面是 4:3 裁切后的照片，看不清原图细节（构图、人脸、文字）。用户希望在详情里点一下照片就能看完整原图。

## 范围

- 要做：
  - 用户端回忆详情，封面有照片时点击打开全屏查看。
  - 查看层显示未裁切的完整图片（`object-fit: contain`），支持双指/双击缩放与拖动。
  - 关闭方式：点右上 ✕、点背景、按 Esc。
  - 无照片（纯色渐变）时没有查看入口。
  - 打开/关闭不改变当前回忆索引和轮播位置。
- 不做（非目标）：
  - 不做相册图集、不做左右滑动切图（查看层固定当前这一张）。
  - 不做下载、分享、长按保存按钮。
  - 不改管理端、不改上传逻辑、不改数据结构。
  - 不改其他页面（小灶菜品图、恋爱卡二维码等）。

## 验收标准

1. 有照片的回忆详情，点击封面能打开全屏原图。
2. 打开后看到的是未裁切原图（4:3 之外的部分也能看到）。
3. 点 ✕、点背景、按 Esc 都能关闭，关闭后仍停留在当前回忆。
4. 没有照片的回忆点封面没有任何反应。
5. 移动端滑动切换回忆仍然正常，不与点按混淆（滑动不算点击）。
6. 320 / 390 / 1280 正常，console 无报错。
