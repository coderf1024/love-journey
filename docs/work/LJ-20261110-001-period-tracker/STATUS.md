## 2026-11-19 读路径修正（AI）

发现一个与验收标准 #6 直接冲突的缺陷并修掉：

- **问题**：`loadCycle()` 每次读都调 `recalcCyclePrediction()`，从不读 `periods.json` 里的 `prediction` 缓存。后果是 `asOf` 每次打开都是当天（界面「预测于 … 生成 · 没有重算」是假话）、距上次开始超过 90 天时读路径自己翻成 `stale`、写进文档的 `dataVersion` 没人读。
- **修法**：新增 `cycleReadPrediction(cached, items, settings, today)`（`js/cycle.js`，纯函数）。读只允许动 `overdueDays` 和 stale 标记，`center` / `range` / `asOf` 原样返回；缓存缺失时内存现算、标记 `ephemeral`、不写回。
- **顺带收紧写路径**：`saveCycleSettings()` 只在 `autoTune` / `algorithmOverride` 变化时重算；其余显示类设置只写 `settings.json`（`settingsOnly`），不重写 `periods.json`。
- **提醒 fail closed**：`settings.json` 不存在 → `remindEnabled: false` + `settingsExists` 透出给管理端。
- **首页细条 / 空间行的 stale 文案**：`cycle-ui.js` 在 `reason === 'stale'` 时改说「该记一次了 / 上次记录在 90 天以前」，不再说「记满 3 次就能预测」（她已经记过，只是太久）。
- 缓存 token → `20261119-01`；`node --check` 全过（含三个页面的内联脚本）；R1–R10 代码级用例 + B1–B8 浏览器用例见 `QA.md`。

## 2026-11-19 粘贴导入（AI，按人的反馈）

美柚的「导出数据」入口不可用，所以导入多了第二条路：**粘贴数据**。抓包拿到的接口返回、客服给的数据文本，粘进「从美柚导入」即可。

- 解析器 `cycleImportFromText()`（`js/cycle-import.js`，纯函数）：JSON 能解析就找 start/end 配对（毫秒时间戳 / ISO / `YYYYMMDD`），否则退回全文抽日期再合并相邻天。
- **「预测」字段与整块一律跳过**：名字匹配 `predict|forecast|expect|next|预测|预计` 的键和它下面的子树都不导入——否则回测对标的是厂商的推算。
- 文本里用 `-` / `~` / `至` / `到` / `to` 连接的两个日期视为一次经期的开始和结束；逗号、分号、换行不合并。
- 走到同一套预览 → 按开始日去重 → `importCyclePeriods`。
