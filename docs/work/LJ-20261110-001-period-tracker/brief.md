## 定位（已由人确认）

- **核心 = 记录 + 预测**。这两件事「打不赢也不能输」：不追求比美柚更强，追求不弱于它、并且在可解释性上更强。
- **两个人的照顾协议 = 锦上添花，不是核心**。容易做成伪需求，二期再看。
- **社区/内容 = 完全不做**。
- **隐私 = 人判断不敏感**，按现有明文方案存 OSS，不做客户端加密。

## 背景与目标

她现在用美柚记录生理期。美柚的核心功能（记录、预测）本身达标，缺点集中在商业模式副作用（广告、社区、电商返现、功能臃肿）和黑盒预测。

目标：

1. 记录不比美柚慢（一次点击完成「今天来了」）。
2. 预测不比美柚差，**并且可解释**：给出区间而不是假精确的单日，显示样本量和历史偏差，能从「这次不准」里学习。
3. 把历史数据从美柚搬过来，解决冷启动——这是「预测不输」的最短路径。
4. 有一个**稳定、免费**的定时提醒通道（见开放问题 1）。

## 范围

### 一期要做

1. **记录**：`今天来了` / `今天结束了` 一键；支持补录开始/结束日、修改、删除、标「记不清」；流量/症状/情绪为可选，不阻塞主流程。保存后用**弹窗**反馈（记了什么 / 偏差几天 / 下次预测 / 撤销）。
2. **日历**：生理期页默认视图，月历展示已记录（实心）、预测（虚线圈）、导入来源（金色点）、**排卵期色带与排卵日（青色，与经期粉色区分）**；点日期弹底部操作（这天开始的 / 经期中一天 / 去掉这天）。日历只读，不在格子上涂抹。
3. **排卵日 / 排卵期**：排卵日 = 下次预计开始日 − 14 天，排卵期 = 前 5 天到后 1 天。口径为「推算值 · 参考值」，不写受孕概率、不叫安全期、明确不能作为避孕或备孕依据；管理端可关闭，她也能单独收起。
4. **预测**：滚动窗口（默认最近 6 个周期）加权中位数 → 下一个开始日；**区间固定 3 天（不因波动放宽），不给单日**；展示样本量、波动、置信度；`这次不准` 反馈参与重算。
5. **预测的触发与跨度**：**只有数据写成功后才重算**；预测日过了不重算（分不清是算错还是没记），只把界面改成「已过 N 天」、区间原样保留；Worker 只读缓存发通知、不补算。**一次只预测下一个周期**（只画一段 3 天虚线），不预测第 2、3 次。
6. **自检（信任来源）**：回测「过去 N 次预测落在区间内几次、平均偏差几天」，直接把准确率摊开给她看。
7. **导入美柚**：上传导出文件 → 列映射 → 预览 → 去重合并 → 写入。兼容「一次经期一行」和「一天一行」两种形态。字段对口见 notes.md。
8. **提醒（定时）**：Cloudflare Workers Cron 每天 09:00 检查一次，按 `daysBefore`（默认提前 1 天 + 当天）推送 Bark；模板可配置（`小灶` 同款 `title/subtitle/body/url` + 变量），默认文案可直接出现「经期」。
9. **入口**：「我们」首页**独立细条，按需出现**——只在「距下次 ≤ 7 天」或「经期中」显示；其余时间首页完全不提，入口只留在「空间 → 生理期」。**不新增底部 tab。**
10. **分工**：用户端只做记录和查看，**没有任何配置开关**；阈值、提醒时间与文案模板、算法开关、清空记录全部在管理端「系统 → 生理期」。大厨不能替她记录、看不到逐日明细。
11. **必输防线**：无广告、无内容流、单页完成、离线可写（先本地后同步）。

### 二期（本次不做）

- 大厨照顾清单、厨房联动（经期友好/忌口）、一键求助、回顾页。
- 与「岁月留痕」并排的叙事。
- 避孕 / 同房记录。

### 非目标

社区、内容流、广告、电商、备孕/怀孕/育儿模式、医学诊断或用药建议、男性独立 App。

## 验收标准

1. 390px 下：打开 → 点「今天来了」→ 看到更新后的预测，全程 ≤ 2 次点击，无表单。
2. 预测卡片展示 3 天区间、样本量、波动、置信度；不足 3 个周期时明确显示「数据不够，先记录」而不是硬给日期；**任何情况下区间都不超过 3 天**。
3. 「这次不准」后，下一次预测结果会变化（权重/样本更新可见）。
4. 回测数字与手算一致（用测试库里的固定样本核对）。
5. 导入美柚文件后：期数、首末期日期与文件一致；重复导入不产生重复记录。
6. 预测触发：打开页面但数据没变时 `asOf` 与区间都不变；跨过中心日后重新打开**不重算**，卡片显示「已过 N 天」且区间保持原样；记录一次后才更新。
7. 预测跨度：日历上只有一段虚线；有效周期 < 3 或距上次开始 > 90 天时不出现预测。
8. 提醒：到点能收到 Bark，点开直达入口；推送失败不阻塞任何记录操作。
9. 首页细条：距下次 > 7 天时不出现；≤ 7 天或经期中时出现；阈值在管理端改动后立即生效。
10. 日历：已记录 / 预测 / 导入 / 排卵期 / 排卵日可区分；点日期弹出三个操作且都不误伤已有记录；排卵日点开写明「推算值、不可用于避孕或备孕」。
11. 过期提醒：第 3 / 5 / 7 / 10 天各推一次，之后不再推；期间一旦记录即停止后续推送。
12. 用户端无任何配置开关；管理端改配置后用户端生效。
13. 320 / 390 / 1280 无横向溢出；console 无报错；`node --check` 通过。
14. 全部验证在 `db-test`，线上库零写入。
