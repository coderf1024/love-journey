# LJ-20261113-001 · 六一素材图生图提示词

## 为什么不再继续抠

现有素材 `assets/media/cat/0b7035a5fc9d5df21a03eb052ddeb76e.jpg` 本身就是「猫贴在纯白底上」的成品：底边是硬切的直线、左肩是一块方角。Vision 抠图只能去掉白底，**改不了轮廓**，所以放在近乎白色的纸面上几乎看不出差别。要得到自然的趴/睡边缘，必须让模型按真实猫体重新生成。

## 用法

1. 用**图生图**（上传参考图 `0b7035a5fc9d5df21a03eb052ddeb76e.jpg`），相似度/重绘幅度建议 **0.35–0.5**：太低会保留原来的硬边，太高会丢掉猫的长相。
2. 一次只生成一张，一次一个姿态。
3. 输出优先选**透明底**（即梦 / Seedream 支持直接导出 PNG 透明底）。工具不支持就选**纯白底 #FFFFFF**，我这边用同一套流程抠。
4. 长边 ≥ 1536px，构图留白 8% 左右，方便后面压卡片边缘。
5. 生成好的原图放到 `assets/media/cat/`，命名 `liuyi-lie-src.png` / `liuyi-sleep-src.png`，我来处理成生产用 WebP。

## 通用前缀（两条提示词都先带上）

> 图生图，参考图中的是一只橘白相间的幼猫。**保持这只猫的长相、毛色、花纹和蓝灰色眼睛完全一致**，不要换猫、不要改变年龄。

## 趴姿（我们页用）

> 图生图，参考图中的是一只橘白相间的幼猫。保持这只猫的长相、毛色、花纹和蓝灰色眼睛完全一致。
>
> 把它重画成一张真实的趴姿照片：小猫整个身体平趴在地面上，**前爪并拢向前伸出、搭在身前**，胸口贴地，后腿收在身体两侧，尾巴贴着地面露在身后，头微微抬起看向镜头，眼睛睁大。
>
> 身体必须**完整出现在画面内**，四只爪子和尾巴都不能被画面边缘裁切，四周留出约 8% 的空白。
>
> 毛发的边缘要**自然蓬松**，能看清一根根细软的毛，尤其在耳朵、脸颊、胸前和爪子处；**不要出现任何笔直的硬边**。
>
> 纯白背景 #FFFFFF，无缝，**没有阴影、没有地板纹理、没有道具、没有文字**。
>
> 摄影质感：柔和自然光，色彩真实不过饱和，浅景深，超清细节，正面平视角度。
>
> **负面提示词：** 裁剪、切边、直线边缘、硬边、白边、描边、投影、地面纹理、毯子、多余的腿、多只猫、文字、水印、logo、卡通、插画、3D 渲染、模糊、低分辨率、暗背景、杂乱背景

## 睡姿（空间页用）

> 图生图，参考图中的是一只橘白相间的幼猫。保持这只猫的长相、毛色、花纹和蓝灰色眼睛完全一致。
>
> 把它重画成一张真实的**蜷睡**照片：小猫侧躺蜷成一团，**前爪收在胸前**，后腿蜷起，尾巴绕到身前贴着身体，头枕在自己的爪子上，**眼睛闭着**，耳朵放松地贴在头上。
>
> 身体必须完整出现在画面内，四周留出约 8% 的空白；采用**四分之三侧面**角度，能同时看到脸和蜷起的身体，一眼看出是在睡觉。
>
> 毛发边缘自然蓬松，能看清细软的绒毛；**不要出现任何笔直的硬边**。
>
> 纯白背景 #FFFFFF，无缝，**没有阴影、没有地板纹理、没有道具、没有文字**。
>
> 摄影质感：柔和自然光，暖色但真实，浅景深，超清细节。
>
> **负面提示词：** 睁眼、裁剪、切边、直线边缘、硬边、白边、描边、投影、地板纹理、毯子、猫窝、多余的腿、多只猫、文字、水印、卡通、插画、3D 渲染、模糊、低分辨率

## 如果只能用 Midjourney

在提示词末尾加参数，并去掉「图生图」三个字，用 `--iw` 控制参考图权重：

```
<提示词> --ar 4:3 --iw 1.2 --style raw --v 6.1
```

## 生成后我会做什么

1. 用 Vision 前景分割 + 白底解混 + 去白边，输出 `liuyi-lie.webp` / `liuyi-sleep.webp`；
2. 在纯黑 / 奶油 / 青绿三种底色下 2 倍放大检查白边；
3. 替换原型里的趴姿和睡姿占位，重新截 320 / 390 / 1280。
